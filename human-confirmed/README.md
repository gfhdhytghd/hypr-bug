# Human-confirmed evidence

No existing issue has an explicit human review and test record in this tracker. This directory currently contains no confirmed issue submissions.

Use `<category>/<issue-id>/` for each submission. Include:

- `REPORT.md`: issue ID and scope, human reviewer identity and review date, exact tested source revision, environment/hardware, review findings, test steps, expected and observed results, evidence, and limitations.
- Reproduction code, patches, logs, or other supporting artifacts as applicable. State which exact versions were reviewed and tested, and how each supplied patch was validated.
- The human verdict: `confirmed`, `partially`, or `rejected`; explain unsupported parts or rejected diagnoses. Update the README tracker to match the human record.

**AI-generated reports, code, and patches are allowed, but a human must review them, confirm they are correct, and test them before they are placed here.** An agent's source review, successful build, automated test, or reproduction run alone does not satisfy this requirement. Report the actual test scope; isolated tests do not establish physical HDR or display acceptance.

For CM bounty eligibility, claim the issue and agree the price with the maintainer before starting public work. Meeting this directory's evidence requirements alone does not establish a bounty agreement.
